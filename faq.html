Frequently Asked Questions

1. What is Clean Kampala Hub?

It is a student website prototype that shares waste-management information for Kampala residents.

2. Which areas does the website cover?

It focuses on Central, Kawempe, Makindye, Nakawa and Rubaga divisions.

3. Does the website collect rubbish?

No. It provides information and is not a waste collection company.

4. Are the collector details real?

No. The directory entries shown are fictional examples for demonstration only.

5. Can I report illegal dumping?

You can complete the demonstration report form, but it does not send a report to KCCA.

6. Why should I separate waste?

Separating waste can make recycling and safer disposal easier.

7. Is this an official KCCA website?

No. It is a student project and is not affiliated with KCCA.
